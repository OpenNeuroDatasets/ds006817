These data were recorded from 35 subjects using the following exclusion criteria: Normal, or corrected-to-normal vision.

Subjects completed a novel, visual contextual trajectory paradigm (CTP) wherein the colour, shape, and/or orientation of a bound stimulus object changed within trial-level sequences. The context of this change was designed to appear random (and unsurprising) or violate the established trajectory (and cause a surprise). Full method details can be read within the following published paper: https://doi.org/10.1016/j.cortex.2025.11.007
